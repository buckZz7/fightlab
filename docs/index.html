03 / Path to the ring

Sim today.
Steel tomorrow.

Phase 1 — Now

Sim gauntlet

Balance → punching → full self-play boxing with ELO-rated kings. Domain randomization from day one: mass, friction, and actuator gear jitter every episode, so policies can't overfit to perfect physics. Challenges run in CI; losers get a cooldown, kings get defended.

Phase 2

One real robot

Deploy the king's balance policy on a single Unitree G1. Sim2Real transfer is the whole ballgame — this is where the randomization budget pays off.

Phase 3

Real bout

Two robots, one ring, fully autonomous. World-first learned robot boxing match. Entertainment on the outside, contact-robustness benchmark on the inside.
