How It Works

01

Motion Tracker

Imitates human combat mocap — punches, kicks, blocks — retargeted to the G1's 29-DoF body. Learns balance, weight transfer, natural movement.

02

Combat Fine-Tune

RL with combat rewards on top of the tracker. Learns to hit, face the opponent, close distance, stay standing. Full combat: punches, kicks, spins.

03

League

Round-robin bouts with ELO scoring. Top challenger gets a title shot against the king. 10-point must per round. KO, fall, or decision.

04

Evolution

Each king gets archived. Next challenger trains against all past kings + scripted opponents. The league never stops evolving.

Combat Rules

🥊

Full Combat

Punches, kicks, knees, elbows — all legal

💀

Head = 2x

Head hits devastating — incentivizes blocking

🦵

Kicks = 1.5x

More mass, more velocity, more damage

🤝

Draws

Damage gap < 2 HP = draw round. No coin flips.

🏆

King Stays

Must BEAT the king to take the crown. Draw = king wins.

📊

10-Point Must

3 rounds × 20s. KO, fall, or decision.

Trustless Eval

🔒 Deterministic

Fixed seeds (42, 123, 777). Same result every run, any machine.

🔑 Model Hashed

SHA256 verified. Can't swap models mid-eval.

📋 Bout Logs

Per-step HP + damage JSON published. Fully auditable.

🤖 GitHub Actions

Runs in CI, not our infrastructure. Anyone can reproduce.
