01How It Works

STAGE 1 — MOTION TRACKER

Learn to move

Imitates human combat mocap (punches, kicks, blocks) retargeted to the G1's 29-DoF body. Learns balance, weight transfer, and natural movement.

STAGE 2 — COMBAT FINE-TUNE

Learn to fight

RL with combat rewards on top of the tracker. Learns to hit (damage), face the opponent, close distance, and stay standing. Full combat: punches, kicks, spins.

STAGE 3 — LEAGUE

Compete for the crown

Round-robin bouts with ELO scoring. Top challenger gets a title shot against the current king. 10-point must per round, KO/fall/decision.

EVOLUTION

Always evolving

Each new king gets archived. The next challenger trains against all past kings + scripted opponents. The league never stops improving.

02Combat Rules

🥊

Full Combat

Punches, kicks, knees, elbows — all legal

💀

Head = 2x Damage

Head hits devastating — incentivizes blocking

🦵

Kicks = 1.5x

More mass, more velocity, more damage

🤝

Draws Exist

Damage gap < 2 HP = draw round. No coin flips.

🏆

King Stays on Draw

You must BEAT the king to take the crown

📊

10-Point Must

3 rounds × 20s. KO, fall, or decision.

03How to Enter

Fork the repo

Clone github.com/buckZz7/fightlab

Train your fighter

train_motion_tracker.py → train_combat.py

Test locally

deterministic_eval.py --fighter models/my_fighter.zip

Submit a PR

Add your .zip to models/ and open a pull request

CI runs trustless eval

Deterministic, multi-seed, hashed, auditable — runs in GitHub Actions

Pass the gate → title bout

Win ≥1 bout, deal ≥1 damage, win on ≥2 seeds. Beat the king to take the crown.

04Trustless Evaluation

🔒

Deterministic

Fixed seeds (42, 123, 777). Same result every run.

🔑

SHA256 verified. Can't swap models mid-eval.

📋

Bout Logs

Per-step HP + damage JSON. Fully auditable.

🤖

GitHub Actions

Runs in CI, not our infrastructure. Anyone can reproduce.
