FightLab 🥊

Autonomous humanoid combat league — Unitree G1 robots fight via RL in MuJoCo

What is FightLab?

FightLab is a king-of-the-hill league where Unitree G1 humanoid robots learn to fight using reinforcement learning. Fighters are trained via a 3-stage pipeline:

  • Stage 1 — Motion Tracker: Imitates human combat mocap (punches, kicks, blocks) retargeted to the G1's 29-DoF body
  • Stage 2 — Combat Fine-Tune: RL with combat rewards (damage, facing, approach, survival) on top of the tracker
  • Stage 3 — League: Round-robin bouts with ELO scoring. Top challenger fights the king for the crown

How to Enter

  1. Fork the repo
  2. Train your fighter using the pipeline:
    python3 train_motion_tracker.py --steps 2000000 --out models/my_tracker
    python3 train_combat.py --tracker models/my_tracker.zip --steps 1000000 --out models/my_fighter
  3. Test in the league:
    python3 league.py --entrants models/my_fighter.zip scripted:jabbler scripted:defender --pd
  4. Submit a PR with your .zip model. CI auto-runs the league gate (ELO ≥ 1400, ≥1 win)
  5. Title bout: if your fighter passes CI, it gets a title shot against the current king

Rules

  • Full combat: punches, kicks, knees, elbows all legal
  • Scoring: 10-point must per round (3 rounds, 20s each)
  • Damage: Head hits = 2x, body = 1x, kicks = 1.5x, leg kicks = 0.5x
  • Win: KO (HP ≤ 0), knockdown (fall), or decision (points)
  • Weapons: Wrists (punches) + ankles (kicks) = damage sources

Tech Stack

  • Physics: MuJoCo (GPU-accelerated via EGL rendering)
  • Training: PPO via Stable Baselines3, 16 parallel envs
  • Mocap: exptech/g1-moves dataset (retargeted to G1 29-DoF)
  • Platform: Unitree G1 (29-DoF, bare-handed wrist-as-fist)
  • Rendering: EGL 720p, broadcast tracking camera
